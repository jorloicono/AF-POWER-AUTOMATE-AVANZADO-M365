# Sesión 1 · Práctica 1.2 · Plantillas, flujos programados y expresiones

*Guardar adjuntos de Outlook en OneDrive y enviar un resumen diario calculado con expresiones*

| Dato | Valor |
|---|---|
| Duración | 40 minutos |
| Nivel | Inicial |
| Archivos | Ninguno |
| Resultado | Un flujo automatizado creado desde plantilla y personalizado, y un flujo programado que envía cada mañana un resumen con fechas y cálculos hechos con expresiones |

# Objetivo

En la Práctica 1.1 construiste un flujo instantáneo desde cero. Ahora vas a trabajar los otros dos tipos de flujo de nube: el **automatizado**, que se dispara solo cuando ocurre algo, y el **programado**, que se ejecuta en una fecha y hora. Empezarás por una plantilla, que es la forma más rápida de tener algo funcionando, y la personalizarás. Después crearás un flujo programado y usarás tus primeras **expresiones** para trabajar con fechas, textos y números.

> **Expresiones en Power Automate.** Las expresiones usan siempre la coma como separador y las cadenas van entre comillas simples: `formatDateTime(utcNow(), 'dd/MM/yyyy')`. No dependen del idioma del navegador.

# Parte 1 · Flujo automatizado desde plantilla

1. En `https://make.powerautomate.com`, abre **Plantillas** y busca `Guardar archivos adjuntos de correo electrónico de Office 365 en OneDrive para la Empresa`.
2. Abre la plantilla y lee la descripción: qué desencadenador usa y qué conexiones necesita.
3. Comprueba que las conexiones de **Office 365 Outlook** y **OneDrive para la Empresa** aparecen con una marca verde y pulsa **Continuar** (o **Crear**).
4. Abre el flujo creado con **Editar** y recorre sus pasos: el desencadenador *Cuando llega un nuevo correo electrónico (V3)* y la acción de crear archivo dentro de un bucle *Aplicar a cada uno*, que se ha añadido solo porque un correo puede traer varios adjuntos.

# Parte 2 · Personalizar la plantilla

1. Selecciona el desencadenador y abre **Parámetros avanzados** (en el diseñador clásico, *Mostrar opciones avanzadas*).
2. Configura los filtros para que el flujo solo procese lo que te interesa:

| Parámetro | Valor |
|---|---|
| Incluir datos adjuntos | Sí |
| Solo con datos adjuntos | Sí |
| Filtro de asunto | `Factura` |
| Carpeta | Bandeja de entrada |

3. Selecciona la acción **Crear archivo** y cambia la **Ruta de acceso de la carpeta** para que cada mes tenga su carpeta. Usa una expresión:

```
concat('/Facturas/', formatDateTime(utcNow(), 'yyyy-MM'))
```

4. Cambia el **Nombre de archivo** para que incluya la fecha y el remitente delante del nombre original. Combina expresión y contenido dinámico:

```
concat(formatDateTime(utcNow(), 'yyyyMMdd'), '_', triggerOutputs()?['body/from'], '_')
```

Y a continuación, fuera de la expresión, añade el contenido dinámico *Nombre de datos adjuntos*.

5. Guarda el flujo. Envíate un correo con asunto `Factura prueba` y un PDF adjunto. En un par de minutos, comprueba en OneDrive la carpeta `Facturas/<año-mes>` y el archivo renombrado.
6. Abre el **Historial de ejecuciones de 28 días** del flujo y revisa la ejecución.

> **Latencia de los desencadenadores.** Los desencadenadores de Outlook se comprueban cada pocos minutos, según la licencia. Si el flujo no se ejecuta al instante, espera o usa **Probar > Manualmente** y envía el correo mientras el flujo está a la escucha.

# Parte 3 · Flujo programado con resumen diario

1. Pulsa **+ Crear > Flujo de nube programado**. Nombre: `Resumen diario de la mañana`.
2. Configura la periodicidad: a partir de mañana, **Repetir cada 1 Día**. Pulsa **Crear**.
3. Selecciona el desencadenador **Recurrence** y configura en parámetros avanzados:

| Parámetro | Valor |
|---|---|
| Zona horaria | (UTC+01:00) Bruselas, Copenhague, Madrid, París |
| A estas horas | 8 |
| En estos minutos | 0 |

> **Días laborables.** Para que solo se ejecute de lunes a viernes, cambia la frecuencia a **Semana** y marca los cinco días en *En estos días*.

4. Añade la acción **Office 365 Outlook > Obtener vista de calendario de eventos (V3)**: calendario *Calendario*, **Hora de inicio** con la expresión `utcNow()` y **Hora de finalización** con `addHours(utcNow(), 12)`. Devuelve los eventos de las próximas doce horas.
5. Añade **Redactar** (conector *Operación de datos*) y renómbrala `Fecha de hoy` (puntos suspensivos > *Cambiar nombre*). En **Entradas** escribe la expresión:

```
formatDateTime(convertFromUtc(utcNow(), 'Romance Standard Time'), 'dddd, dd \de MMMM \de yyyy', 'es-ES')
```

6. Añade otro **Redactar** llamado `Días hasta fin de mes`:

```
sub(dayOfMonth(addDays(startOfMonth(addToTime(utcNow(), 1, 'Month')), -1)), dayOfMonth(utcNow()))
```

7. Añade **Enviar un correo electrónico (V2)** a ti mismo con asunto `Buenos días, ` + salida de *Fecha de hoy*, y un cuerpo que diga cuántos días quedan de mes y cuántos eventos tienes hoy. Para el número de eventos usa la expresión `length(outputs('Obtener_vista_de_calendario_de_eventos_(V3)')?['body/value'])`, insertándola desde el editor de expresiones y eligiendo la salida en el contenido dinámico para que el nombre interno sea el correcto.

# Parte 4 · Un flujo manual para practicar expresiones (opcional)

Si has terminado las partes anteriores antes de tiempo, haz esta calculadora; si no, hazla en casa. La demo D1.3 cubre las mismas expresiones.


1. Crea un **flujo instantáneo** llamado `Calculadora de moqueta` con dos entradas de número: `Superficie` (m²) y `Coste` (€/m²).
2. Añade un **Redactar** `Importe` con la expresión:

```
mul(triggerBody()?['number'], triggerBody()?['number_1'])
```

3. Añade un **Redactar** `Importe con IVA`: `mul(outputs('Importe'), 1.21)`.
4. Añade un **Redactar** `Importe formateado`: `formatNumber(outputs('Importe_con_IVA'), 'N2', 'es-ES')`.
5. Añade un **Redactar** `Fecha de validez`, 15 días desde hoy: `formatDateTime(addDays(utcNow(), 15), 'dd/MM/yyyy')`.
6. Envíate una notificación móvil con el texto `Presupuesto: ` + *Importe formateado* + ` € (válido hasta ` + *Fecha de validez* + `)`.
7. Prueba con 20 m² y 12,5 €. Debe salir `302,50 €`.

> **Nombres internos.** `triggerBody()?['number']` es el nombre interno de la primera entrada numérica y `number_1` el de la segunda. Si tienes dudas, abre el editor de expresiones y selecciona la entrada desde el contenido dinámico: Power Automate escribe el nombre correcto por ti.

# Comprobación

- Tienes un flujo automatizado creado desde plantilla con filtros y rutas personalizadas.
- Tienes un flujo programado a las 8:00 hora de Madrid que envía un resumen con fecha en español.
- Si has hecho la Parte 4, la calculadora devuelve importes con IVA y formato español.
- Sabes insertar expresiones y leer su resultado en el historial de ejecuciones.

# Tabla de expresiones de esta práctica

| Expresión | Para qué sirve |
|---|---|
| `utcNow()` | Fecha y hora actual en UTC |
| `convertFromUtc(fecha, 'Romance Standard Time')` | Pasar a hora de Madrid |
| `formatDateTime(fecha, 'dd/MM/yyyy')` | Dar formato a una fecha |
| `addDays(fecha, n)` · `addToTime(fecha, n, 'Month')` | Sumar tiempo |
| `startOfMonth(fecha)` · `dayOfMonth(fecha)` | Partes de una fecha |
| `concat(a, b, ...)` | Unir textos |
| `mul(a, b)` · `sub(a, b)` · `add(a, b)` · `div(a, b)` | Operaciones |
| `formatNumber(n, 'N2', 'es-ES')` | Número con formato español |
| `length(matriz)` | Número de elementos |
